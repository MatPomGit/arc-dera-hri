# Rejestr decyzji architektonicznych

ADR dotyczą granic dokumentacji, bezpieczeństwa i narzędzi, nie treści pytań i decyzji o metodologii psychometrycznej.

- [ADR-0001: oddzielenie publikacji i dokumentacji wewnętrznej](0001-pages-boundary.md) – **proposed**.

Każdy ADR wymaga daty, stanu, kontekstu, alternatyw, konsekwencji i dowodów zatwierdzenia. `proposed` nie jest przyjętą decyzją projektową ani zezwoleniem na publikację.
