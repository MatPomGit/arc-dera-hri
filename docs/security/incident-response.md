# Procedura reagowania na incydent

**Stan: NOT_CONFIGURED.** Brak aktywnego dyżuru.

W przypadku podejrzenia wycieku danych uczestnika, tokenów lub dokumentów wewnętrznych zabezpiecz minimalne dowody, ustal zakres, wersję i commit SHA, a zgłoszenie przekaż prywatnie uprawnionemu właścicielowi. Nie wpisuj danych do Issues i nie usuwaj historii bez autoryzacji.

Ograniczenie dostępu, rotacja poświadczeń, powiadomienia i odpowiedzialność prawna wymagają indywidualnej oceny. Wynik naprawy potwierdź konkretnymi testami oraz przeglądem rzeczywistej widoczności witryny.
