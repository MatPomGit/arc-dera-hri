# Bezpieczeństwo i ochrona danych DERA-HRI

**Status: CONTACT_NOT_CONFIGURED.** Projekt nie deklaruje gotowego prywatnego kanału zgłaszania podatności ani dyżuru.

W publicznym repozytorium wolno przechowywać wersjonowane, przeznaczone do udostępnienia banki pytań i puste formularze. Nie zapisuj w nim wypełnionych ocen ekspertów, transkrypcji wywiadów, danych identyfikujących uczestników, zgód, nagrań ani kluczy i danych dostępowych. Dane badawcze wymagają osobnej, kontrolowanej lokalizacji, podstawy prawnej, uprawnień i retencji.

GitHub Pages publikuje wyłącznie odrębne `pages/` po sprawdzeniu jawnej listy zasobów, treści i widoczności. Nawet prywatne repozytorium nie gwarantuje prywatności Pages. Nie publikuj workflow agentów, notatek redakcyjnych i planów operacyjnych. Bezpieczeństwo zależy od rzeczywistych ustawień GitHub i świadomej decyzji właściciela.

Luki i podejrzenie ujawnienia kieruj prywatnie do rzeczywiście uprawnionego właściciela; nie twórz publicznych Issues z danymi poufnymi. [Model zagrożeń](docs/security/threat-model.md), [procedura reagowania](docs/security/incident-response.md) i [polityka Pages](docs/pages.md).
